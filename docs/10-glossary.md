# Glossary

- **GSTIN** — 15-character GST registration number of a person/business.
- **Taxable value** — the rent amount on which GST is charged.
- **CGST / SGST** — central and state GST; each 9% for intra-state supplies.
- **IGST** — inter-state GST (not used here; all supplies are within Tamil Nadu).
- **GSTR-1** — monthly statement of outward supplies (sales/rent invoices).
- **GSTR-3B** — monthly summary return where tax is paid.
- **B2B** — supply to a GST-registered recipient (all tenants here).
- **SAC** — Service Accounting Code; 997212 for commercial property rental.
- **RCM** — Reverse Charge Mechanism; "N" here (tax paid by the owner, not tenant).
- **QRMP** — Quarterly Return Monthly Payment scheme (optional).
