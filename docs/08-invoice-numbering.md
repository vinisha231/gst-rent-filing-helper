# Invoice numbering

Each owner keeps **one continuous series per financial year** (April-March):

- J Lavanya -> `LR/NN/FY`
- Prema Jyothilingam -> `PJ/NN/FY`
- Sharmila Baladhayanidhi -> `SR/NN/FY`

`NN` increases by one for every invoice and **resets to 01 each April**, with the
FY label rolling over (e.g. `2026-27` to `2027-28`). The records in
`data/registers/` already carry the next suggested number for every month.
