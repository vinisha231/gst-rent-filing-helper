# SAC code 997212

All these invoices use **SAC 997212 — "Rental or leasing services involving own
or leased non-residential property."** That is the correct service accounting
code for renting out commercial / non-residential premises.

- It is taxed at **18%**.
- It goes in the **HSN/SAC summary** (Table 12 of GSTR-1).
- Keep the same code every month so the returns stay consistent.
