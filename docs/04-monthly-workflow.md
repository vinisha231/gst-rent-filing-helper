# The monthly routine

Do this every month for each owner:

1. **Raise invoices** on the 1st (or last day) of the month — one per tenant.
   Use the next running invoice number (the app/records suggest it).
2. **Collect rent + GST** from each tenant.
3. **File GSTR-1** by the **11th** of the next month — list each invoice (B2B).
4. **File GSTR-3B** by the **20th** of the next month — pay the CGST + SGST.
5. **Tick it off** in that month's tracker file under `data/trackers/`.

The per-owner figures to type into GSTR-3B box 3.1(a) are shown on each owner
card in the app and in `data/filing/<owner>/<month>.json`.
