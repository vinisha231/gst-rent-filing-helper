# FAQ

**Is the rent figure inclusive of GST?**
No. The rent is the *taxable value*. GST of 18% is **added on top**.

**What if a month's rent changes?**
Edit that unit's `data/registers/<unit>/<month>.json` (and `js/data.js`), then the
totals update. The calculator on the site also splits any custom amount.

**Do all three owners file together?**
No. Each GSTIN files its own GSTR-1 and GSTR-3B. The app groups by owner for you.

**Is this an official tool?**
No. It is a working aid to organise the numbers. Always confirm the final return
with a qualified accountant / GST practitioner.
