# Filing GSTR-3B (monthly)

GSTR-3B is the summary return where you actually pay the tax.

1. Log in -> Returns -> select month -> **GSTR-3B**.
2. **Box 3.1(a) Outward taxable supplies**: enter the month's **total taxable
   value**, and the **CGST** and **SGST** amounts (IGST and cess are 0).
3. Proceed to payment — deposit cash equal to CGST + SGST (no input credit is
   assumed here).
4. Offset liability -> File with DSC/EVC.

Use `gstr3b.section_3_1_a_outward_taxable` from the filing sheet, or the figures
on the owner card in the app. **Due date: 20th of the following month.**
